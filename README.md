# Olivier Hollebeke - Portfolio ✨

> "Passionné par l'univers IT dans sa globalité, l'analyse et la compréhension des nouvelles technologies"

Un portfolio personnel pensé "Ultra Premium" utilisant une esthétique moderne afin de mettre en valeur mes projets, certaines de mes passions et mon parcours.

🌍 **[Consulter le Site en Direct](https://portfolio-three-navy-20.vercel.app/)**

## 🌟 Fonctionnalités & UX

- **Design "Glassmorphism"** : Interfaces épurées avec un effet de verre dépoli superposé sur des orbes colorées et mouvantes.
- **Expérience Parallax** : Des éléments subtilement ancrés à la position du curseur sur l'écran pour une perception de véritable profondeur de champ.
- **Micro-interactions 3D (Tilt)** : Les différentes cartes s'orientent physiquement en 3D lors du survol de la souris.
- **Parcours "Timeline"** : Suivi chronologique de mes études et implications professionnelles.
- **Fully Responsive** : Un "Hamburger menu" et une "Grid" mobile qui s'adaptent instantanément du grand écran d'ordinateur à la verticalité d'un smartphone.

## 🛠 Technologies utilisées

Pour garantir des performances optimales (60 FPS permanents sans Framework encombrant) :
- **HTML5** propre et sémantique
- **CSS3 / Variables Custom** (Système Dark Mode Ultra Premium, Gradients & Flou Gaussien)
- **Vanilla JavaScript** (Animation Request, IntersectionObserver, Manipulation du DOM en 3D)
- **Vite** (Pour le serveur de développement et l'optimisation locale)
- **Vercel** (Pour l'hébergement continu)

## 💻 Lancer le projet en local

Si vous souhaitez tester directement l'application sur un environnement de développement local :

1. Clonez le dépôt GitHub.
2. Installez au préalable Node.js et NPM.
3. Installez les dépendances dev associées au projet :
   ```bash
   npm install
   ```
4. Lancez le serveur local :
   ```bash
   npm run dev
   ```
5. L'application devrait héberger par défaut sur `http://localhost:5173`.
